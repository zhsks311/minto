데이터 안내

음성은 Mac 안에, AI 정리는 선택한 만큼만.

회의 음성은 전사를 위해 외부 서버로 보내지 않습니다. 다만 교정, 요약, 답변 생성에 클라우드 AI를 고르면 필요한 텍스트가 전송될 수 있습니다.

로컬

회의 음성은 Mac에서 전사합니다

마이크와 시스템 사운드는 기기 안에서 처리합니다. STT 모델은 내려받을 수 있지만, 회의 음성 자체를 전사하려고 서버에 올리지는 않습니다.

선택

클라우드 AI는 직접 고를 때만 사용합니다

교정, 요약, 답변 생성에 클라우드 AI를 선택한 경우에만 회의 텍스트가 외부로 전송될 수 있습니다. 로컬 AI를 고르면 이 범위를 줄일 수 있습니다.

보관

토큰은 Keychain에 저장합니다

API 토큰 같은 비밀값은 기본적으로 macOS Keychain에 저장합니다. 개발용 파일 저장은 사용자가 따로 선택한 경우에만 씁니다.

회의 음성마이크, 시스템 사운드, 혼합 입력Mac 안에서 전사
전사 텍스트회의 중 쌓이는 텍스트와 저장된 전사클라우드 AI 선택 시 전송 가능
검색 답변저장된 회의에서 찾은 관련 근거 조각답변 생성을 요청할 때만
참고 문서로컬 파일, Notion, Confluence 문서필요한 요약·발췌만 사용
토큰과 키AI 서비스, Confluence 같은 연동 비밀값Keychain 저장
로그오류 진단과 상태 추적용 이벤트프롬프트·토큰·전사 원문 제외

클라우드 AI를 선택하더라도 전체 회의를 무조건 보내는 구조가 아닙니다. 기능에 필요한 텍스트, 요약, 발췌, 근거 조각을 구분해서 사용하는 방향으로 설계합니다.

민감한 회의 전에 확인할 것

  • 클라우드 AI를 선택했는지 확인합니다.
  • 회의 주제, 용어집, 참고 문서에 민감한 내용이 있는지 확인합니다.
  • Confluence로 내보내기 전에는 위치와 제목을 확인합니다.
  • 민감한 회의라면 로컬 AI를 쓰거나 요약·답변 기능을 끄고 사용합니다.
